# v9 Python 冒險任務版

## 學生體驗固定原則
1. 學生畫面一次只呈現「目前一個挑戰」，不一次攤開整關或全部課程。
2. 小地圖只顯示附近進度；未抵達關卡以雲霧／神秘區域呈現。
3. Python 成功執行且符合基本任務要求後，才取得星星並前進。
4. 每完成三個小挑戰開一次寶箱，並解鎖下一大關。
5. 第十關完成後頒發「Python 畢旅冒險完成證書」。
6. 證書可輸入學生姓名，列出完成技能、30 顆星與完成日期，支援瀏覽器列印／存成 PDF。
7. 教師預覽可直接跳至 30 個挑戰，不修改學生進度。
8. 學生端維持冒險、星星、徽章、寶箱等語言，不出現成績權重、採計或百分比。

## 後續資料庫
未接資料庫前，姓名與闖關進度保存在 localStorage。
未來接教師自有資料庫時，再回傳學生、關卡、星星、技能、完成時間與證書紀錄。
