# Python 逐步解鎖規格（v8 起固定）

學生端 Python 維持 P1～P10 單一路線，不另設重複課程。

## 解鎖規則
- 第 1 關第 1 個小任務預設開放。
- 每個小任務必須先成功執行，並通過該任務的基本程式結構驗證，才取得星星並解鎖下一個小任務。
- 每關 3 個小任務全部完成後，才解鎖下一大關。
- 未解鎖內容仍顯示名稱與鎖頭，讓學生知道前進方向，但不能跳關。
- 已完成任務可回去重玩，不會失去星星。
- 第 10 關完成後解鎖「程式改造基地」。
- 教師預覽模式全部開放，且不改變學生 localStorage 進度。

## 教學體驗
學生感受到的是「完成 → 星星 → 解鎖 → 前進」，不顯示計分、採計、百分比或成績權重。
