# Python 單一路線整合規格（v7 起固定）

## 核心原則
原本 P1～P10 就是學生唯一的 Python 闖關主線。新增教學鷹架必須直接融入這十關，不得再建立「核心課程 → 原版實戰」兩套重複路線，也不得在學生端出現「原版實戰」等區隔名稱。

## 十關連續能力線
1. 哈囉，旅伴！ → print
2. 畢旅報名表 → 變數、input
3. 旅費分攤 → int、運算、//、%
4. 健康檢查 BMI → float、**、round
5. 雲霄飛車身高檢查 → 比較、True/False、if/else
6. 自動購票機 → if/elif/else
7. 極速飛車雙重關卡 → and/or
8. 遊覽車發車倒數 → for/range
9. 置物櫃密碼鎖 → while
10. 魔王關猜數字 → random + while + if 綜合應用

每關內採「理解 → 試跑 → 修改 → 小挑戰 → 星星」逐步增加難度。十關結束後才進入「改造 → 加料 → 自創」。
