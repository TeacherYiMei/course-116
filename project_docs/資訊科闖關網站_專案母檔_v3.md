## 1. 專案定位

保留原版九年級資訊科技闖關網站的教材、關卡、小程式與遊戲化精神，在此基礎上逐步改良成：

## 2. 不可任意破壞的原則

1. 原版教材、關卡、小程式、互動遊戲、Bonus 優先保留。
2. 新功能優先接在原版後面或以新入口整合，不任意刪除好用內容。
3. Python 不只教語法，必須由小步驟鷹架走向原版實作、自由探索與自創程式。
4. 學生端避免「計分、採計、百分比、成績權重」等字眼。
5. 學生感受到的是：闖關、星星、徽章、愛心、寶箱、解鎖、作品與成就。
6. 教師端才進行幕後星星統計、授課單元設定與未來學期成果換算。
7. 分數／量化資料與成就分開：學生即使總量化表現不同，已完成的技能與作品仍須保留為成就。
8. 教師版可直接查看所有後續關卡內容，不必先完成前關。
9. 學生學習採「概念 → 操作 → 挑戰 → 實作 → 自由探索」。
10. 所有新課程都要能回答：學生學會什麼、做了什麼、最後產出什麼。

## 4. Python 核心教學主線

固定依邏輯順序建立學習鷹架：

1. Print → 電腦說話
2. 變數 → 電腦記住資料
3. Input → 電腦聽人說話
4. 運算 → 電腦幫你算
5. 比較 → 電腦判斷 True / False
6. if / elif / else → 電腦做選擇
7. while → 電腦在條件成立時重複做事
8. for / range → 電腦依規則重複做事
9. 綜合應用 → 學生做出完整小程式

核心教法：同一情境拆成數個連續小題，每題只增加一個新概念，讓學生從模仿、修改、預測、除錯逐步走向獨立完成。

## 5. Python 題目設計範例

### A. 自我介紹階梯
1. Print：直接輸出「我是XXX，今年XX歲。」
2. 變數：name、age，再輸出。
3. Input：輸入姓名、年齡，再輸出。
4. 增加年級輸入。
5. 使用 int(input())，進行可計算的數字處理，例如明年年級。

### B. BMI 階梯
1. 固定數字與次方運算 **。
2. 建立 weight、height 變數。
3. input() 輸入體重、身高並計算。
4. 加入姓名與 round(bmi, 2)。
5. 延伸運算概念至 //、% 等。

BMI 核心示意：
weight = 70
height = 1.75
bmi = weight / (height ** 2)
print(round(bmi, 2))

### C. 條件判斷階梯
1. 比較運算，先看到 True / False。
2. if：單一條件。
3. if / else：二選一。
4. if / elif / else：多重條件。
5. 自動購票機。
6. 成績等第。
7. 找錯誤：冒號、縮排、條件順序。

常用比較：
==、!=、>、<、>=、<=

### D. while／猜數字階梯
1. answer 與 guess 比較，輸出 True / False。
2. if / else：答對／答錯。
3. while：沒有猜中就繼續。
4. > / <：提示太大／太小。
5. random.randint(1, 9)：答案隨機。
6. 延伸：猜測次數、範圍 1～100、限制次數等。

教學重點：while 內必須讓控制條件有機會改變，避免無限迴圈。

## 13. Python 載入問題

已確認原版 Python 會建立 Web Worker 並載入 Pyodide。
直接雙擊 HTML 使用 file:// 時，部分瀏覽器會阻擋 Worker／外部資源，因此可能永遠停在「Python 載入中」。

目前版本已加入提示／偵測方向，但正式測試應在 http:// 或 https:// 環境進行。
